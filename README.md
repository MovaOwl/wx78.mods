# wx78.mods

Моды для Don't Starve Together про WX-78.

## wx1102

WX-78 получает:

- **прыжок Вортокса**: по ПКМ, по клавише к курсору (Z) и через карту. Бесплатно;
- **Кодекс Умбра Максвелла** в стартовом инвентаре: все заклинания бесплатно, до 6 слуг;
  открывается клавишей X;
- **крафт без станций**: станции, магазины и ивентовые станции доступны везде, ресурсы тратятся.

Каждую способность и обе клавиши можно поменять в настройках мода.
Подробности и устройство — в [docs/DESIGN.md](docs/DESIGN.md).

### Установка

1. Скопируй папку `wx1102` в
   `Steam/steamapps/common/Don't Starve Together/mods/`.
2. В игре: **Моды** → включи **wx1102** → при желании поменяй настройки.
3. Мод нужен всем игрокам на сервере (`all_clients_require_mod`).

### Если что-то сломалось

Пришли файл `Документы/Klei/DoNotStarveTogether/client_log.txt`
(для выделенного сервера ещё `server_log.txt`).
