# wx78.mods

Моды для Don't Starve Together.

| Мод | Что это | Релизы |
|---|---|---|
| [wx1102](#wx1102) | WX-78 с прыжком Вортокса, Кодексом Умбра и крафтом без станций | теги `v*` |
| [Trickster](#trickster) | Бабочка, которая перевоплощается в любого персонажа | теги `trickster-v*` |

## wx1102

WX-78 получает:

- **прыжок Вортокса**: по ПКМ, по клавише к курсору (Z) и через карту. Бесплатно;
- **Кодекс Умбра Максвелла** в стартовом инвентаре: все заклинания бесплатно, до 6 слуг;
  открывается клавишей X;
- **крафт без станций**: станции, магазины и ивентовые станции доступны везде, ресурсы тратятся.

Каждую способность и обе клавиши можно поменять в настройках мода.
Подробности и устройство — в [docs/DESIGN.md](docs/DESIGN.md).

### Установка

1. Скопируй папку `wx1102` в
   `Steam/steamapps/common/Don't Starve Together/mods/`.
2. В игре: **Моды** → включи **wx1102** → при желании поменяй настройки.
3. Мод нужен всем игрокам на сервере (`all_clients_require_mod`).

### Если что-то сломалось

Пришли файл `Документы/Klei/DoNotStarveTogether/client_log.txt`
(для выделенного сервера ещё `server_log.txt`).

## Trickster

Новый персонаж — Бабочка-трикстер: летает, не голодает, хрупкая. Клавишей **C** перевоплощается
в любого персонажа игры (18 + Вонки) и обратно, с твоим древом навыков этого персонажа.
Стартовые вещи облика приходят и уходят вместе с ним. Подробности — в
[docs/TRANSFORM.md](docs/TRANSFORM.md).

Установка — как у wx1102, папка `trickster`.

## Выпуск релиза

1. Поменять `version` в `<мод>/modinfo.lua`.
2. По желанию — заметки в `release-notes/<тег>.md` (`v0.2.0` для wx1102, `trickster-v0.2.0` для Trickster).
3. GitHub → **Actions** → **Release** → **Run workflow**, указать папку мода.
